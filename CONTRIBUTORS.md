## Contributors

This project is new and looking for contributors! If you'd like to contribute, please see [CONTRIBUTING.md](CONTRIBUTING.md).

### How to be listed here

Contributors are added after their first merged pull request. To be listed:

1. Submit a pull request
2. Once merged, your name and GitHub handle will be added here

### Recognition

All contributors are recognized in:
- This CONTRIBUTORS.md file
- GitHub's contributor graph
- Release notes for relevant releases
